# 物理实验室 · Laboratorio di Fisica I

面向意大利大学 **Fisica I（Meccanica + Termodinamica）** 的互动物理模型网站。界面为中文，术语附意大利语，可一键切换为意大利语为主（考试是意大利语）。

纯静态 HTML/CSS/JS：无需构建、无外部依赖、可离线使用。直接打开 `index.html`，或部署到 GitHub Pages。按电脑端（1366–1920 px，键盘鼠标）设计。

## 内容

**35 个互动模型**，每个都有可调参数、动画、实时图表（悬停十字线读数）、实时数据、概念说明和关键公式，下方附例题与常见错误。

| 章节 | 模型 |
|---|---|
| 预备知识 Prerequisiti | 矢量与微积分（标量积、矢量积、导数、积分） |
| 运动学 Cinematica | 一维运动、抛体、圆周运动、极坐标与自然坐标、相对运动 |
| 动力学 Dinamica | 斜面与摩擦、阿特伍德机、非惯性系与惯性力（电梯、离心、科里奥利） |
| 功与能 Lavoro ed energia | 能量守恒、非保守力的功 W_nc = ΔE、势能曲线 U(x) 与平衡稳定性 |
| 动量与碰撞 Quantità di moto | 冲量与功率、碰撞与质心（含二维斜碰）、火箭运动 Δv = u ln(m₀/m_f) |
| 刚体 Corpo rigido | 转动惯量与滚动、角动量守恒（花样滑冰）、质点与刚体碰撞、杠杆平衡 |
| 振动 Oscillazioni | 阻尼/受迫振动与共振、单摆（大角度精确周期、阻尼 ω_d） |
| 万有引力 Gravitazione | 轨道、开普勒定律、逃逸速度 |
| 流体 Fluidi | 静压与浮力、连续性与伯努利 |
| 温度与热 Calore | 比热与相变、热膨胀、热传导、对流与辐射（Stefan–Boltzmann、Wien） |
| 气体 Gas | 分子动理论（3D 麦克斯韦分布，标出 v_p、⟨v⟩、v_rms）、四种基本过程、范德瓦尔斯气体 |
| 第一定律与循环 | 第一定律与路径、卡诺/奥托/狄塞尔循环与制冷机 COP |
| 第二定律与熵 | 熵与自由膨胀、克劳修斯不等式 |

## 备考功能

- **例题**：每个模型都有“先预测再运行”的例题，可填答案核对、展开分步解答、一键用对应参数运行模型；另附常见错误。
- **章节测验**（`#quiz/章节`）：意大利语题干 + 中文，选项随机打乱，答完立即显示对错和解释。
- **随机练习**（`#problemi`）：数字随机生成，答案由同一套公式计算，可在模型中验证。
- **学习进度**（`#home`）：按章节统计已看模型、例题、测验最高分和练习次数，保存在浏览器 localStorage。
- **公式速查**（`#formule`）：按章节列出公式与单位，可筛选。
- **中意术语表**（`#glossario`）：150+ 个术语，中文/意大利语双向搜索。
- **单位换算**（`#unita`）：能量（J、cal、L·atm、eV…）、压强、体积、速度、温度等。
- **中文 / Italiano** 切换在右上角。

快捷键：`/` 搜索主题，`空格` 播放/暂停，`R` 重置，`[` `]` 上一个/下一个模型。

## 文件结构

- `index.html`：页面框架
- `css/style.css`：样式（极简风格，浅色界面 + 深色模拟画布）
- `js/core.js`：控件、图表（含悬停读数）、动画接口
- `js/mech1.js` – `js/mech4.js`：力学模型
- `js/thermo.js`、`js/thermo2.js`：热学模型
- `js/exam.js`：章节划分、例题、测验题库、随机题生成器、进度
- `js/pages.js`：学习进度、测验、随机练习、公式速查、术语表、单位换算页面
- `js/app.js`：路由（`#cicli`、`#quiz/gas` 等）、导航、快捷键、动画循环

单位均为国际单位制（SI），g = 9.81 m/s²，R = 8.314 J/(mol·K)。
